## 🚀 Quick Start

### 1. Deploy Your Server (5 minutes)

**Easiest: Render.com**
1. Push to GitHub
2. Go to Render.com → New Blueprint
3. Connect repo
4. Deploy!

Your URLs:
- **Coordinator:** `https://ollama-coordinator.onrender.com`
- **Public API:** `https://ollama-proxy-sh88.onrender.com`

### 2. Share with EditorAI Users

Tell them to use this URL in EditorAI settings:
```
https://ollama-proxy-sh88.onrender.com
```

### 3. Get GPU Donors

Share **DONOR_GUIDE.md** with people who want to help.

They just need to:
```bash
python worker/client.py
```

That's it!
